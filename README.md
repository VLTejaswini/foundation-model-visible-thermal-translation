# Foundation Model Guided Physics-Informed Multimodal Diffusion Framework

## Project Overview

A research-oriented AI software system for cross-spectral
thermal-to-visible image translation and scene understanding.

## Objective

Translate thermal/infrared images into plausible visible-spectrum
RGB images while preserving structural information.

## Software Engineer Module

The Software Engineer is responsible for:

- Application architecture
- Image upload
- Preprocessing integration
- AI inference integration
- RGB output handling
- Evaluation integration
- Batch processing
- Video translation
- Testing
- Deployment
- Documentation
